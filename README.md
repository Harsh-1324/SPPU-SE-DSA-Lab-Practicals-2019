# SPPU-SE-DSA-Lab-Assignments-2019
Data Structures &amp; Algorithms Lab assignments for Second Year Computer Engineering (2019 Course) under Savitribai Phule Pune University. Includes solved programs, algorithms, and mini-projects using C++ and Python.

📌 Overview
This repository contains lab assignments for SPPU SE Computer Engineering (2019 Course) subject:

210257: Data Structures & Algorithms Laboratory

Includes implementations, algorithms, and outputs for various DSA concepts.

🎯 Objectives
Understand core Data Structures concepts

Implement efficient algorithms

Solve real-world problems using DSA

Improve coding and problem-solving skills

🧪 Lab Structure
🔹 Group A – Hashing & Sets
Hash Table (Collision Handling)

Dictionary ADT

Skip List

Set ADT Operations

🔹 Group B – Trees
Binary Search Tree (BST)

Expression Tree

Threaded Binary Tree

Huffman Coding

🔹 Group C – Graphs
DFS & BFS

Graph Representation

Minimum Spanning Tree

Shortest Path Problems

🔹 Group D – Advanced Topics
Scheduling Algorithms

Optimization Problems

C++ (G++/GCC)
